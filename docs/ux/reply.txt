R3 siap direview. Dialog reward sekarang menampilkan saldo terbaru, biaya tersimpan, dan kekurangan poin sebelum keputusan. Pada saldo 20 dan biaya 80, terlihat kurang 60 poin; Setujui nonaktif, Tolak tetap tersedia, dan permintaan tetap pending untuk ditinjau nanti.

Perubahan saldo/status memperbarui dialog tanpa menghapus alasan. Jika perubahan baru terdeteksi saat klik, keputusan belum diterapkan dan informasi terbaru perlu ditinjau ulang. Coba “Skenario review → Konflik reward”, lalu kontrol “Skenario review lokal” di dalam dialog untuk mensimulasikan saldo berubah.

R2 sudah diarsipkan. Uji browser mobile/desktop, dua tab asli, serta Lavish sandbox lulus. Aturan D2 tetap sama; R3 belum dianggap disetujui.

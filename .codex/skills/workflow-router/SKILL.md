# Workflow router
Read AGENTS.md, state, intake, and existing specs. Classify as new-product, feature, bugfix, refactor or release. For a new product start discovery. For an existing app assess impact and do not blindly repeat discovery. Do not mark a stage completed without evidence. Use `python scripts/workflow.py status` and `validate`. Pause for explicit approvals. Resume from persisted state after interrupted sessions. Route UI projects through ux-prototype skill.

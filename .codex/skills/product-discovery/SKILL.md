# Product discovery
Identify target users, problem, success metrics, jobs-to-be-done, key flows, MVP, non-goals, constraints, functional and non-functional requirements, edge cases and measurable acceptance criteria. Ask only blocking questions. Use docs/PRODUCT-TEMPLATE.md. Record assumptions separately from confirmed facts. Obtain explicit product scope approval before advancing.
